# SoCute 💗

### Turn your SORRY into something beautiful.

SoCute is an AI-powered personalized apology website generator designed to help people express their feelings through beautiful, customized apology pages.

Instead of sending a simple text message, users can create a personalized apology experience with meaningful messages, creative themes, and a unique design.

## ✨ Features

### Currently Implemented
- 🎀 Beautiful pastel-themed landing page
- 📝 Multi-step apology creation form
- 💌 Recipient name and relationship selection
- 🌍 Multiple language options
- ✍️ Different writing styles and emotional tones
- 🎨 Multiple theme selections
- 👀 Personalized apology preview
- 💗 Interactive preview experience

### Planned Features
- 🤖 AI-generated personalized apology messages using Google Gemini
- 🎨 AI-assisted theme customization
- 🔗 Unique shareable website links
- 📱 QR code generation
- 📥 Downloadable apology websites
- 🖼️ Optional photo and music customization
- 💾 Save and manage created apology pages

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SOUHARDGUPTA/SoCute.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SoCute
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal (usually `http://localhost:5173/`).
